Este projeto foi desenvolvido como um **CRUD de revisão**, focado em consolidar o conhecimento sobre o ecossistema Django, integração com banco de dados relacional (PostgreSQL) e o processo de deploy em ambiente de produção.

---

## 🚀 Funcionalidades

* **🛠️ CRUD Completo:** Cadastro, leitura, atualização e exclusão de veículos.
* **🔍 Filtros Inteligentes:** Sistema de busca integrada que permite filtrar automóveis por:
    * **Valor:** Encontre veículos dentro da sua faixa de preço.
    * **Tipo:** Filtre por categorias (Sedan, SUV, Hatch, etc).
* **🌐 Deploy Contínuo:** Aplicação hospedada no Render, utilizando PostgreSQL como banco de dados de produção.

---

## 🏗️ Arquitetura Técnica

O projeto segue o padrão **MVT (Model-View-Template)** do Django:

* **Models:** Mapeamento das entidades de veículos no Postgres.
* **Views:** Lógica de processamento e filtragem dos dados.
* **Templates:** Interface renderizada dinamicamente para o usuário.
